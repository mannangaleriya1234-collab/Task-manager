# Task Management System

## Project Description

This project is a simple Task Management System made using HTML, CSS and JavaScript.

It allows users to add, view, edit and delete tasks. The project also has a priority filter and search feature to help users manage their tasks easily.

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Set task priority
- Filter tasks by priority
- Search tasks
- Save tasks using Local Storage
- Data remains saved after refreshing the page
- Validation for task title and due date
- Responsive design

## Task Fields

Each task contains:

- Task Title
- Description
- Due Date
- Priority

Priority options:

- Low
- Medium
- High

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add tasks using the form.
5. Use the search and priority filter to find tasks.

## Local Storage

The project uses browser Local Storage to save task data.

This means tasks will remain available even after refreshing the browser page.

## CRUD Operations

The project performs all basic CRUD operations:

- **Create** - Add a new task
- **Read** - Display tasks
- **Update** - Edit a task
- **Delete** - Delete a task

## Validation

The project checks that:

- Task title is entered.
- Due date is selected.

If either field is missing, the user receives an alert.
